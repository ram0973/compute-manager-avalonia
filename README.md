# Компьютеры AD

Утилита администратора для Windows-домена на **C# / .NET 11 / Avalonia**: таблица компьютеров и пользователей из Active Directory с быстрыми удалёнными действиями из контекстного меню.

![Главное окно с открытым контекстным меню](docs/screenshot.png)

## Возможности

**Вкладка «Компьютеры»** (правый клик по строке; Ctrl/Shift — несколько ПК):

| Действие | Как работает |
|---|---|
| RDP, Shadow RDP, Dameware | `mstsc`, `mstsc /shadow` с выбором сеанса (qwinsta), `dwrcc.exe` |
| Удалённая консоль | cmd, PowerShell 5, PowerShell 7 через PsExec (в т.ч. от SYSTEM) |
| Сеансы, «Кто вошёл» | `qwinsta /server:`; «Кто вошёл» опрашивается при старте и по «Обновить» |
| Управление компьютером, диск C$ | `compmgmt.msc /computer=`, проводник |
| Обновление данных (группа в меню) | «Кто вошёл», «Свободно на C:» (`GetDiskFreeSpaceEx` по `\\ПК\C$`), «Касперский» |
| Касперский | служба `AVP*`, автоматически раз в час |
| gpupdate /force | PsExec от SYSTEM |
| Установка программ | окно с каталогом пакетов (`Install\packages.json`) и выбором ПК, проверка SHA-256 |
| Wake-on-LAN, пинг, IP, MAC | MAC определяется по ARP и запоминается |

**Вкладка «Пользователи»**: логин, ФИО, телефон из AD. Правый клик → «Найти ПК, где пользователь залогинен» — опрос онлайн-ПК, переход на вкладку «Компьютеры» и выделение найденных.

Тёмная и светлая темы, колонки по ширине содержимого, журнал сообщений внизу окна, справка (кнопка **?** или F1).

## Требования

- Windows (PsExec, mmc, qwinsta, проверка диска и Касперского); просмотр AD работает и в Linux/macOS.
- Права администратора на целевых ПК, доступ по SMB (445); для `qwinsta` — RPC.
- .NET 11 SDK (или `net10.0` + `LangVersion 14` в `.csproj`).

## Сборка и публикация

```
dotnet publish -c Release -p:PublishProfile=ProductionProfile
```

Положите перед сборкой (или добавьте позже через окно «Установка программ»):

```
Install\PsExec64\PsExec64.exe
Install\7-zip\7-zip.msi        (и любые другие установщики)
```

Папка `Install` копируется в `bin` и в publish автоматически. Скрипты из `Scripts\` **вшиваются в exe** и рядом с программой не лежат.

## Безопасность

- **Скрипты** (`Scripts\*.ps1`) вшиты в exe и достаются оттуда во время работы — на проде их нельзя подменить, не заменив сам exe. На целевой ПК скрипт копируется под случайным именем, и перед запуском проверяется его SHA-256.
- **Установщики** сверяются с SHA-256 из `Install\packages.json` на этой машине и повторно на целевом ПК до запуска.
- Каталог пакетов и `PsExec64.exe` — доверенные файлы: разрешите запись в папку `Install` только администраторам.
- Имена хостов, попадающие в командную строку, проверяются по белому списку символов.
- Подписывайте exe (Authenticode).

## Файлы настроек

`%AppData%\ComputerManager\`: `macs.json` (кэш MAC), `theme.txt`, `dameware.json` (параметры `dwrcc`), `logs\` (журналы установок и gpupdate).
